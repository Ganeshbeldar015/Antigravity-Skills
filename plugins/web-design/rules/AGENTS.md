# Web Design & UX Systems Behavioral Guidelines

When `web-design` is active:
1. Think visually first with strong grids, generous whitespace, disciplined typography, and restrained color palettes.
2. Maintain clear visual hierarchy: one primary focal point per screen, clear heading progression (H1 > H2 > Body > Label).
3. Follow accessibility standards: minimum 44x44px touch targets, WCAG AA color contrast, and keyboard navigation.
4. When translating distinct aesthetic styles (Bauhaus, Pop Art, Retro, Futuristic), adhere strictly to the foundational movement rules.
5. Provide actionable specifications (exact CSS/Tailwind tokens, layout structures, and spacing rhythm) rather than generic guidance.
