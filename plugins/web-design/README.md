# Web Design & UX Systems Plugin

> Production Google Antigravity Plugin

## Overview
Web graphic design, UI/UX systems, layouts, typography, and visual styling (Bauhaus, Pop Art, Retro, Futuristic) derived from the acclaimed `claude-code-in-avinyc` ecosystem by Avi Flombaum.

## Features
- **Skills**:
  - `web-design`: Visual graphic design, typography scales, color contrast, and style translation (Bauhaus, Pop Art, Retro, Futuristic).
  - `ux-ui`: Information architecture, interaction design, Turbo/Stimulus patterns, accessibility, and responsive layouts.
- **Agents**:
  - `web-designer`: Autonomous frontend graphic designer and design system architect.
- **Rules**: Consolidated `rules/AGENTS.md` applied automatically when active.

## Installation
Clone or copy into your Antigravity plugins directory:
- Project level: `.agents/plugins/web-design`
- Machine global: `~/.gemini/config/plugins/web-design`

```bash
python scripts/install.py web-design --scope global
```
