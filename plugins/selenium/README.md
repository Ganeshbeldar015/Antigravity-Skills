# Selenium WebDriver MCP Plugin

> Production Google Antigravity Plugin

## Overview
Selenium WebDriver MCP server by Angie Jones. Automated cross-browser testing, DOM interaction, element navigation, and web accessibility verification.

## Features
- **MCP Server**: Stdio integration executing `npx -y @angiejones/mcp-selenium`.
- **Skills**: `selenium-automation` for browser navigation, clicking, typing, and screenshots.
- **Agents**: `cross-browser-tester` for automated end-to-end QA.
- **Rules**: Consolidated `rules/AGENTS.md` applied automatically when active.

## Installation
Clone or copy into your Antigravity plugins directory:
- Project level: `.agents/plugins/selenium`
- Machine global: `~/.gemini/config/plugins/selenium`

```bash
python scripts/install.py selenium --scope global
```
