# Storyflow Behavioral Guidelines

When `storyflow` is active:
1. Always structure project boards hierarchically: Epics > User Stories > Tasks with acceptance criteria.
2. Maintain consistent visual layout standards: arrange flow nodes with distinct horizontal stages (To Do, In Progress, In Review, Done) and logical branch connections.
3. Validate OAuth connection status before attempting canvas mutations or card creations.
4. Keep user story cards actionable: include clear "As a [role], I want [capability], So that [benefit]" framing.
5. Provide markdown previews of cards and workflow states to the user before committing large-scale board updates.
