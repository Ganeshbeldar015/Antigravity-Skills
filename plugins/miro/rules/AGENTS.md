# Miro Visual Whiteboard Behavioral Guidelines

When `miro` is active:
1. Organize sticky notes and shapes with consistent grid spacing and thematic color codes.
2. Group related items within named Miro frames (e.g., "Research", "Ideation", "Architecture").
3. Use bulk creation tools (`bulk_create_items`) when generating multiple cards to optimize API rate limits.
4. Verify that `MIRO_OAUTH_TOKEN` is present in the environment before triggering board write operations.
